# ls.bat

I know you always reach for `ls` in a windows environment. Don't try to change, just let it happen.

It will delegate to GnuWin32's ls if you've got it... Feel free to comment that out if you don't want to do that. Otherwise, it will do a bit of shenanigans to translate ~ into your user profile directory, replace unix-style path separators with the sloppy MS-DOS ones, and add some flashy colours to your outputs. No powershell nonsense, no sketchy unexpected HTTP requests, just a dumb ol' command to list files in a way that feels pretty good.

If you want, change it. Add cool stuff, take dumb stuff out, let me know if it will compromise your enterprise system (I certainly hope not! But maybe...)
